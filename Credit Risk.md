# Входные кредитные показатели:
## Идентификация и применяемый режим
Базовые поля карточки предприятия
- ИНН
- ОГРН или ОГРНИП
- Организационно-правовая форма: ИП или ООО
- Основной ОКВЭД
- Налоговый режим и объект налогообложения
- Отчётный год или налоговый период
- Источник данных и тип документа
- Признак полной или упрощённой бухгалтерской отчётности
## Финансовые показатели ООО
Из бухгалтерского баланса и отчёта о финансовых результатах
- Выручка
- Себестоимость продаж
- Прибыль или убыток от продаж
- Прибыль или убыток до налогообложения
- Чистая прибыль или убыток
- Общая сумма активов
- Собственный капитал
- Краткосрочные и долгосрочные заёмные обязательства
- Кредиторская и дебиторская задолженность
- Денежные средства
- Денежные потоки, если соответствующий отчёт представлен
## Финансовые показатели ИП
Из налогового учёта и дополнительных подтверждающих данных
- Доходы за налоговый период
- Документально подтверждённые и принимаемые расходы, когда они применимы
- Налоговая база и сумма исчисленного налога
- Задолженность по кредитам и займам
- Доступный остаток денежных средств
- Активы и обязательства — если имеются достоверные данные из бухгалтерского учёта, отчётности или документов предпринимателя

# Показатели для вычисления:

- Рыночная позиция (Нужно посмотреть исходя из данных мб возможно)
- Бизнес профиль (Заполняем по годам и т.д.)
- Географическая диверсификация (Объективно тяжело реализуемый показатель с слабым влиянием => выкидываем)
- Корпоративное управление (Также тяжело реализуемо, можно попробовать отразить в бизнес профиле)
- Размер
- Рентабельность
- Долговая нагрузка
- Обслуживание долга
- Ликвидность
- Денежный поток

### Размер
|Показатель|Комментарии|Отрасли|
|---|---|---|
|FFO до % и налогов (операционный денежный поток до изменения оборотного капитала, выплаты процентов и налогов)|Показатель, отражающий объем денежных средств, генерируемых в ходе операционной деятельности. Может быть использован для сопоставления размера рейтингуемых лиц из широкого круга отраслей.|Используется в качестве основного показателя для всех отраслей|
|FFO до фиксированных платежей и налогов|Показатель, отражающий объем денежных средств, генерируемых в ходе операционной деятельности. Рассчитывается до вычета фиксированных платежей и налогов.|ИТ|
|Выручка|Показатель, отражающий валовый оборот операционной деятельности, однако не учитывающий финансовую эффективность.|Оптовая торговля, розничная торговля (вторичный показатель)|
|EBITDA (прибыль до выплаты процентов, налогов, износа и амортизации)|Наиболее широко распространенный показатель операционной эффективности, отражающий объем операционной прибыли, скорректированной на неденежные доходы / расходы. Может быть использован для сравнения размера рейтингуемых лиц из широкого круга отраслей.||
|EBITDAR (прибыль до выплаты процентов, налогов, износа, амортизации и аренды)|Показатель для более широкого сопоставления операционного результата между рейтингуемыми лицами, учитывающий особенности модели владения активами (модель «легких / тяжелых активов»). Широко распространен для сравнения компаний розничной торговли.||
|Прочие|В качестве прочих показателей, определяющих размер рейтингуемого лица, могут использоваться различные количественные данные, как правило, не находящие отражения в официальной отчетности (например, объем добычи/производства, объем разведанных запасов, объем торговых площадей и прочие показатели в зависимости от отраслевой специфики).|Добывающая и обрабатывающая промышленность (объем добычи/переработки); энергетическая промышленность (объем генерации/передачи); телекоммуникации (количество абонентов); недвижимость (размер площадей); строительство (объем портфеля строительства).|

### Рентабельность
|Показатель|Комментарии|Отрасли|
|---|---|---|
|Рентабельность по FFO до % и налогов|Основной показатель для сравнения эффективности деятельности рейтингуемых лиц, демонстрирующий эффективность генерации операционного денежного потока относительно общего оборота.|Все отрасли, кроме транспорта (перевозчики), телекоммуникаций, недвижимости и розничной торговли.|
|Рентабельность по FFO до фиксированных платежей и налогов|Показатель для сравнения эффективности деятельности рейтингуемых лиц, учитывающий различия в моделях владения активами (широко используется в сегменте розничной торговли).|Транспорт: перевозчики; телекоммуникации; розничная торговля; ИТ.|
|Рентабельность по EBITDA(R)|Наиболее широко используемые показатели для сравнения операционной эффективности рейтингуемых лиц нефинансового сектора. Не являются индикаторами эффективности генерации денежного потока. Могут использоваться в качестве вспомогательных показателей.||
|Прочие|В ряде отраслей в качестве вторичных целесообразно оценивать описывающие рентабельность деятельности рейтингуемого лица (например, ARPU, EBITDAR с кв. м, операционная прибыль к объему добычи и другие).|Нефтегазовая отрасль (EBITDA в расчете на баррель); телекоммуникации (ARPU); недвижимость (ставка капитализации, NOI с кв. м); розничная торговля (EBITDAR с кв. м); жилищное строительство (SG&A/выручка).|

|Скорректированный общий (чистый) долг / FFO до платежей|Показатель, отражающий покрытие долговой нагрузки, скорректированной на операционную аренду (для большей сопоставимости компаний), операционным денежным потоком до движения оборотного капитала, выплаты процентов и аренды.|

Имеет ограниченную применимость для большого числа отраслей и используется в качестве вспомогательного фактора для рейтинговой оценки.|
|Общий (чистый) долг / EBITDA|Наиболее широко используемый показатель оценки долговой нагрузки в нефинансовом секторе, отражающий покрытие долговой нагрузки операционной прибылью до выплаты процентов, налогов и амортизации. Имеет ограниченную применимость для большого числа отраслей и используется в качестве вспомогательного фактора для рейтинговой оценки.|
|Общий (чистый) долг / Собственный Капитал|Показатель, отражающий соотношение собственных и привлеченных средств. |Общий долг / NOI|Показатель, отражающий покрытие долговой нагрузки чистым операционным доходом.|

### Ликвидность
|Категория оценки|Коэф. краткосрочной ликвидности|Качественная оценка ликвидности|
|---|---|---|
|I|>1,5|Превосходный уровень ликвидности. Комфортный график погашения долгового портфеля в долгосрочной перспективе. Диверсифицированные источники внутреннего и внешнего финансирования, включающие размещения на публичных рынках долга и/или акционерного капитала. Присутствует высокий запас прочности по ковенантам в кредитных соглашениях.|
|II|1,25–1,5|Высокий уровень ликвидности. Комфортный график погашения долгового портфеля в среднесрочной перспективе. Диверсифицированные источники внутреннего и внешнего финансирования. Имеется определенный запас прочности по ковенантам в кредитных соглашениях.|
|III|1,0–1,25|Умеренная ликвидность. Наличие пиковых периодов погашения долга в среднесрочной или долгосрочной перспективе. Присутствуют внутренние источники финансирования, однако из внешних источников доступно только банковское финансирование. Отсутствие запаса прочности по ковенантам в кредитных соглашениях при отсутствии потребности в наращивании долга.|
|IV|0,8–1,0|Низкая ликвидность. Наличие пиковых периодов погашения долга в краткосрочной перспективе. Исключительная зависимость от банковского финансирования. Отсутствие запаса прочности по ковенантам в кредитных соглашениях при наличии потребности в наращивании долга.|
|V|<0,8|Крайне низкая ликвидность. Наличие пиковых периодов погашения долга в краткосрочной перспективе. Исключительная зависимость от банковского финансирования, при этом существует значительный риск отказа в предоставлении средств. Ковенанты в кредитных соглашениях нарушены. Вероятность улучшения уровня ликвидности в среднесрочной перспективе крайне низка.|

Обозначения:

- **[МОЖНО]** — рассчитывается из перечисленных входных полей, если соответствующие значения заполнены.

- **[ЧАСТИЧНО]** — можно получить только прокси-показатель / приближение либо расчёт возможен не для всех организаций.


  
- Рыночная позиция — **[ЧАСТИЧНО]**: ОКВЭД и выручка помогают описать масштаб, но для доли рынка нужны данные о рынке и конкурентах.

- Бизнес-профиль — **[ЧАСТИЧНО]**: можно сформировать базовый профиль по ОКВЭД и динамике финансовых показателей за несколько лет; для полноценной оценки нужны сведения о продуктах, клиентах и бизнес-модели.

- Корпоративное управление — **[ЧАСТИЧНО]**: полноценная оценка не рассчитывается; отдельные сведения можно позже включить в бизнес-профиль.

- Размер — **[МОЖНО]**: выручка; для ООО дополнительно активы и собственный капитал. FFO/EBITDA/EBITDAR требуют дополнительных данных (см. ниже).

- Рентабельность — **[МОЖНО]**: для ООО можно рассчитать маржу прибыли от продаж, маржу прибыли до налогообложения и чистую маржу.

- Долговая нагрузка — **[ЧАСТИЧНО]**: для ООО можно рассчитать отношение отражённых заёмных средств к собственному капиталу и чистый долг/капитал, если считать чистый долг как займы минус деньги. Полная долговая нагрузка требует проверки полноты долга и дополнительных показателей.

- Ликвидность — **[ЧАСТИЧНО]**: можно рассчитать денежные средства к краткосрочной кредиторской задолженности как ограниченный прокси-показатель. Для стандартного коэффициента текущей ликвидности нужна строка 1200 «Оборотные активы», которой нет в списке входных полей.

- Денежный поток — **[ЧАСТИЧНО]**: если представлен отчёт о движении денежных средств, доступна строка 4100 (сальдо потоков от текущих операций). FFO и FCF требуют дополнительных данных и/или корректировок.

### Формулы, которые можно реализовать сразу для ООО

- **Маржа продаж** = строка 2200 / строка 2110 × 100%.
- **Маржа до налогообложения** = строка 2300 / строка 2110 × 100%.
- **Чистая маржа** = строка 2400 / строка 2110 × 100%.
- **Долг / капитал (приближение)** = (строка 1410 + строка 1510) / строка 1300.
- **Чистый долг / капитал (приближение)** = (строка 1410 + строка 1510 − строка 1250) / строка 1300.
- **Деньги / краткосрочная кредиторская задолженность** = строка 1250 / строка 1520.
- **Динамика выручки** = (выручка текущего года − выручка предыдущего года) / выручка предыдущего года × 100%.
- **Коэффициент текущей ликвидности** = 1200 / 1500

Правила обработки:
1. Не считать отсутствующее поле нулём: хранить `NULL` / «нет данных».
2. Если знаменатель равен нулю, коэффициент не рассчитывать; если знаменатель отрицательный (например, собственный капитал), помечать результат как требующий специальной интерпретации.
3. Для каждого коэффициента хранить год, источник, формулу и признак качества данных.
4. Для сравнения по годам использовать сопоставимые периоды и одну методику расчёта.


# Итоговая формула рейтинга

### 1. Общий вид

```
S(k) = Σ wᵢ(k) · Sᵢ ,   Sᵢ ∈ [0; 1]      (1 = минимальный риск)

S(k) = w_отр·S_отр + w_рп·S_рп + w_бп·S_бп
     + w_разм·S_разм + w_рент·S_рент + w_долг·S_долг
     + w_обсл·S_обсл + w_ликв·S_ликв + w_дп·S_дп

Рейтинг = 1000 · S(k)
```

Здесь k – отрасль компании. Веса зависят от отрасли и берутся из таблицы экспертных весов.

### 2. Веса из таблицы по отраслям

В таблице есть закономерность. Доли внутри блоков одинаковы для всех отраслей и меняется только вес блоков:

- операционный блок: рыночная позиция 30%, бизнес-профиль 40%, география 10%, корпоративное управление 20%;
- финансовый блок: размер 20%, рентабельность 14%, долговая нагрузка 20%, обслуживание долга 20%, ликвидность 6%, денежный поток 20%.

Из этого получаем правила:

```
W_оп(k) = W_фин(k) = (100% − W_отр(k)) / 2
wᵢ(k)   = W_блока(k) · αᵢ
```

Корректировки по вашему файлу (веса блоков из таблицы при этом сохраняются):

- география исключена, её 10% распределены пропорционально, поэтому рыночная позиция получает α = 1/3;
- корпоративное управление включено в бизнес-профиль, поэтому он получает α = (40+20)/90 = 2/3.

Итоговые веса (%) при полном наборе данных:

|W_отр|Отрасли|w_отр|w_рп|w_бп|w_разм|w_рент|w_долг|w_обсл|w_ликв|w_дп|
|---|---|---|---|---|---|---|---|---|---|---|
|0|Добыча, машиностроение, перевозчики, с/х, пищевая, розница, ИТ|0|16,67|33,33|10|7|10|10|3|10|
|5|Нефтегаз, металлургия, химия, генерация|5|15,83|31,67|9,5|6,65|9,5|9,5|2,85|9,5|
|10|ЖКХ и сети, транспорт: инфраструктура, телеком, **«Прочие» (середина диапазона 0–20)**|10|15|30|9|6,3|9|9|2,7|9|
|15|Недвижимость|15|14,17|28,33|8,5|5,95|8,5|8,5|2,55|8,5|

Сумма в каждой строке равна 100.

### 3. Как считать Sᵢ

Все показатели приводятся к шкале 0–1 одной функцией:

```
f(x; a, b) = min(1, max(0, (x − a)/(b − a)))
```

Здесь a – значение, которое даёт 0, а b – значение, которое даёт 1. Если a > b, показатель считается «чем меньше, тем лучше». Пороги ниже – стартовые, их нужно откалибровать на вашем датасете, например взять P10 и P90 внутри отрасли.

**S_отр.** Экспертная оценка отраслевого риска k (0–1). Этих значений у нас пока нет.

**S_рп (рыночная позиция)**

```
S_рп = 0,6·f(ln Выручка; ln P5, ln P95 по отрасли) + 0,4·f(g; −20%, +15%)
g = (Выр_t − Выр_t-1) / Выр_t-1
```

**S_бп (бизнес-профиль и управление)**

```
S_бп = 0,30·f(g; −20%, +15%)
     + 0,25·f(CV выручки по годам; 0,5; 0,1)
     + 0,25·f(возраст по ОГРН, лет; 1; 10)
     + 0,20·S_упр
S_упр = 1, если 1300 > 0 и 1370 ≥ 0; 0,5, если 1300 > 0 и 1370 < 0; 0, если 1300 ≤ 0
```

S_упр здесь только прокси корпоративного управления. CV считается при наличии не менее трёх лет.

**S_разм (размер)**

```
S_разм = 0,5·f(ln 2110) + 0,3·f(ln 1600) + 0,2·f(ln 1300)
```

Границы берутся по P5 и P95 датасета. FFO и EBITDA недоступны, поэтому используется выручка, активы и капитал, как указано в файле.

**S_рент (рентабельность)**

```
S_рент = 0,5·f(2200/2110; 0; 15%) + 0,25·f(2300/2110; 0; 12%) + 0,25·f(2400/2110; 0; 10%)
```

**S_долг (долговая нагрузка)**

```
Долг = 1410 + 1510
S_долг = 0,5·f(Долг/1300; 3; 0,5) + 0,5·f((Долг − 1250)/2200; 6; 1)
```

Особые случаи:

- если 1300 ≤ 0, первое слагаемое равно 0;
- если 2200 ≤ 0 при положительном чистом долге, второе слагаемое равно 0;
- если чистый долг ≤ 0, второе слагаемое равно 1.

2200 здесь играет роль прокси EBITDA, потому что амортизации во входных данных нет.

**S_обсл (обслуживание долга)**

```
S_обсл = f((2300 + 2330)/2330; 1; 5)
```

Нужна строка 2330 «Проценты к уплате». Её нет в вашем списке входных полей, но она есть в отчёте о финансовых результатах. Если процентов нет и долг нулевой, S_обсл = 1.

**S_ликв (ликвидность)** – по шкале категорий из вашего файла, КТЛ = 1200/1500:

|КТЛ|> 1,5|1,25–1,5|1,0–1,25|0,8–1,0|< 0,8|
|---|---|---|---|---|---|
|S_ликв|1|0,75|0,5|0,25|0|

Если 1200 или 1500 отсутствуют, используется запасной вариант: S_ликв = f(1250/1520; 0,05; 0,3).

**S_дп (денежный поток)**

```
S_дп = 0,6·f(4100/2110; 0; 10%) + 0,4·f(4100/Долг; 0; 0,3)
```

При нулевом долге второе слагаемое равно 1.

### 4. Пропуски, форма отчётности, шкала

1. **Пропуски.** Если показатель недоступен, он выбывает из формулы, а остальные веса пересчитываются:

```
   S = Σ_{i∈A} wᵢSᵢ / Σ_{i∈A} wᵢ ,   A – множество рассчитанных блоков
```

Отсутствующее значение не заменяется нулём. Для S_обсл и S_дп так и происходит, если нет строки 2330 или отчёта о движении денежных средств.  
2. **Упрощённая форма.**

- Блок S_дп выбывает, потому что отчёта о движении денежных средств нет.
- Если нет строки 2200, EBIT-прокси считается как 2110 − 2120. Проверьте по вашему датасету, какие строки есть в упрощённой форме.
- Итог ограничивается потолком: `Рейтинг = min(1000·S, R_cap)`, где R_cap – верхняя граница класса A на вашей шкале.

3. **Особые случаи.** Если знаменатель равен 0, коэффициент не считается. Если капитал ≤ 0, действуют правила выше.
4. **ИП.** Вводные заполняются вручную в те же поля, формула остаётся той же.
